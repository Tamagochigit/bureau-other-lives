# Бюро других жизней

Личное веб-приложение: примерить роль, выполнить небольшую миссию, сохранить впечатление и увидеть, к каким занятиям хочется вернуться. Есть сценарии традиций для себя и близких.

Первая версия выбрана пользователем 2026-10-04: веб-приложение. Миссии и оценки — личный эксперимент, без утверждений о психологической диагностике.

## Development

Исходные браузерные файлы находятся в [dist](dist/). Сборка и установка зависимостей не нужны. Для проверки требуется Node.js 22 или новее:

```sh
node scripts/verify.mjs
node scripts/extract-context.mjs
```

Развёртывание: [операции](docs/operations.md). Открывать через HTTP(S); ES-модули не предназначены для запуска двойным кликом через file URL.
