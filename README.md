# Бюро других жизней

Веб-приложение на русском: небольшие миссии, традиции, личный дневник и компас по собственным оценкам. Раздел «Друзья» добавляет личные диалоги и предложение миссии.

Основной текст крупный и контрастный; на главной — выбор времени и места либо продолжение миссии. Дневник остаётся в этом браузере. Сообщения хранятся на сервере и доступны участникам диалога. Это обычный чат без сквозного шифрования, вложений, звонков и фоновых уведомлений.

## Development

Браузерный интерфейс — [public](public/). Серверная граница — [app](app/), чат — [server/social.mjs](server/social.mjs), схема и миграции — [db](db/) и [drizzle](drizzle/). Используется поддерживаемый Sites Vinext starter; Node.js >=22.13.0.

```sh
npm run install:ci
npm run verify
npm run lint
npm run build
npm run context
```

После изменения схемы: `npm run db:generate`; проверить SQL и сохранить новые миграции. Существующие миграции не переписывать. Развёртывание и доступ друзей: [операции](docs/operations.md). Локальный preview запускать только по поддерживаемому Sites workflow для текущей среды.

## Git

Исходники и история версий находятся в Git-репозитории этого Site. Для переносимой копии используется файл `bureau-other-lives.bundle`, который экспортируют после окончательного коммита. Из полученного файла можно создать обычный checkout:

```sh
git clone bureau-other-lives.bundle bureau-other-lives
cd bureau-other-lives
```

GitHub-репозиторий отдельно не создавался. Токены доступа, локальные базы и сообщения не входят в bundle.
