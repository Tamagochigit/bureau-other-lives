# Бюро других жизней

Веб-приложение на русском: небольшие миссии, традиции, личный дневник и компас по собственным оценкам. Раздел «Друзья» добавляет личные диалоги и предложение миссии.

Основной текст крупный и контрастный; на главной — выбор времени и места либо продолжение миссии. Дневник остаётся в этом браузере. Сообщения хранятся на сервере и доступны участникам диалога. Это обычный чат без сквозного шифрования, вложений, звонков и фоновых уведомлений.

## Сайт и исходники

- Основной сайт: https://tamagochigit.github.io/bureau-other-lives/
- Репозиторий: https://github.com/Tamagochigit/bureau-other-lives
- Защищённые чаты: https://bureau-of-other-lives.neurozona.chatgpt.site/#friends

GitHub Pages публикует интерфейс. Чаты и база сообщений продолжают работать на прежнем сервере Sites с входом через ChatGPT. В разделе «Друзья» есть переход туда; предложенная миссия передаётся без заметок и отправляется только после подтверждения в чате. Публичный сайт не предоставляет доступ к чужим диалогам или к закрытому серверу.

Дневник привязан к адресу сайта. Чтобы перенести записи, на прежнем адресе открой настройки и скачай копию; на новом выбери «Восстановить». Записи объединятся. Автоматического переноса личных заметок между доменами нет.

## Development

Браузерный интерфейс — [public](public/). Серверная граница — [app](app/), чат — [server/social.mjs](server/social.mjs), схема и миграции — [db](db/) и [drizzle](drizzle/). Используется поддерживаемый Sites Vinext starter; Node.js >=22.13.0.

```sh
npm run install:ci
npm run verify
npm run lint
npm run build
npm run context
```

Для статического сайта достаточно Node 24, без установки пакетов:

```sh
node scripts/verify.mjs
node scripts/build-pages.mjs
```

Результат — `out/pages`. Публикация запускается из `main` через [.github/workflows/pages.yml](.github/workflows/pages.yml); pull request проходит проверки без публикации. Сервер Sites развёртывается отдельно по [операциям](docs/operations.md), с сохранением D1 и доступа.

После изменения схемы: `npm run db:generate`; проверить SQL и сохранить новые миграции. Существующие миграции не переписывать. Развёртывание и доступ друзей: [операции](docs/operations.md). Локальный preview запускать только по поддерживаемому Sites workflow для текущей среды.

## Git

GitHub — основной адрес проекта. Исходные коммиты Sites импортируются через проверенный Git bundle; импорт добавляет merge-коммит, сохраняя исходные SHA, авторов и даты. Одноразовый workflow [import.yml](.github/workflows/import.yml) после импорта не работает без удалённого из текущего дерева bundle. Результат переноса и проверки записывается в [истории](docs/changes.md).

```sh
git clone https://github.com/Tamagochigit/bureau-other-lives.git
cd bureau-other-lives
```

Репозиторий содержит интерфейс, сервер, схему/миграции, тесты, документацию и историю. Токены доступа, личные дневники, локальные базы и реальные сообщения в Git не входят.
