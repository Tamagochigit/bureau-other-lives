# Project

Milestone: first reviewable personal web application connecting all three selected brainstorm strands. The owner accepted the web format; no broader commercial or native-app programme is implied.

Delivery scope: curated missions, tradition scenarios, local diary, compass and backup. Code and knowledge are one batch. Publication should remain private by default.

Next decisions are conditional on use: if records need to follow devices, specify cloud sync; if the owner wants notifications, define permission and reminder behaviour; if activities feel repetitive, extend the authored catalog. These are future work, not shipped capabilities.

Current authorised batch, 2026-10-04: readability and reduction of visual noise, R08–R09. Earlier proposed feature additions are outside this batch. See [UX](ux.md) and [change provenance](changes.md).

Material verification limit: visual browser/device QA was unavailable. User acceptance awaits the owner's first mission.

Review when milestone, scope or acceptance changes. See [requirements](requirements.md) and [testing](testing.md).
