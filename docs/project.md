# Project

A personal Russian web application joins missions, traditions, diary and a rating compass. Public source/full history and the website are in the owner's GitHub project.

Current authorised batch, 2026-10-05: standalone runtime, a restored unfiltered «Удиви меня» home, no time/place start form, and local shortcuts to existing Telegram conversations instead of a custom messenger. Retain readable typography, five primary views and compatible diary/backup. Old hosted data is not deleted. No payments, cloud diary sync, embedded inbox, notification or new provider account setup.

Completion needs observed tests/build, current knowledge instructions, a fresh reviewer, an ordinary GitHub commit and successful Pages/live checks. Evidence and remaining manual browser/Telegram acceptance are in [changes](changes.md) and [testing](testing.md).

Future decisions depend on use: cloud records, notifications or a larger catalog need an explicit scope change. The unanswered optional messenger choice defaults to external Telegram links; full in-site conversation needs a separately selected, tested service/account flow. Review when milestone, acceptance or scope changes. [Requirements](requirements.md), [product](product.md).

2026-10-05 new milestone: build a directly installable signed APK, cohesive icon/style and a concrete motivation/monetisation proposal. Android acceptance includes packaged offline runtime, diary persistence/recovery, origin/destination restrictions, Back/insets, release lint/build and signature verification. No store submission, production billing, new accounts or hidden analytics is in this milestone. Audience/direct-install defaults are explicit in [android.md](android.md); proposed commercial validation is in [monetization.md](monetization.md). Completion requires observed verification and named device limits, not only configuration.
