# Product

A personal Russian web application combines small adventures, traditions and a compass grounded in the user's own ratings. The outcome is one real attempt followed by an honest reflection, not an inferred personality assessment.

Current owner direction, 2026-10-05: home starts with «Удиви меня», with no time/place form. It draws from the whole catalog while avoiding recently completed experiences when alternatives exist. Existing active progress remains visible below; viewing another mission never replaces it. Beginning a different mission still requires explicit confirmation. Catalog filters remain optional inside their disclosure.

Acceptance: open a surprise, inspect three steps, begin/resume, complete an adapted or partial experience, record a 1–5 rating and optional note/repeat preference, reopen/edit the diary, inspect honest category averages, save favourites/traditions, export and safely merge a backup.

Owner update, 2026-10-07 (Moscow): universal «Поделиться» replaces the Telegram-only implementation. The owner explicitly chose «Без списка»: no separate address book. Android uses its system chooser; supported browsers use Web Share, otherwise clipboard/selectable public text. Friends offers existing joint-activity ideas. Only a chosen authored mission title/invitation/link is passed; the user chooses the application, recipient and final sending action. No message history, inbox, delivery claim or private-note transfer is introduced.

This is a standalone GitHub/Pages product. No product login, platform identity, chat backend, message archive, bot, payments, billable AI, cloud diary sync or unread/online claims. Conversations and existing accounts belong to the external applications chosen by the user. Embedding a full messaging client is a separate decision requiring a verified production provider/account flow.

Diary v1 and backups remain compatible. The retired local contacts key is left untouched without current reads/writes/deletion. Historical chat/Telegram records in [changes](changes.md) and [decisions](decisions.md) describe earlier releases. [Requirements](requirements.md), [architecture](architecture.md) and [testing](testing.md) define current acceptance and limits. Review when scope, start, sharing or data boundaries change.

Historical 2026-10-05 Android milestone (Telegram routing superseded by universal sharing): a direct-install pilot shares the authored catalog and diary semantics, bundles content offline and delegates Telegram externally. It has a warm open-door icon and a count of distinct completed roles in the diary. No payment or retention result is claimed. Audience defaults to adults seeking novelty because the optional question had no answer. [Android](android.md) owns runtime/recovery; [motivation and monetisation](monetization.md) owns commercial hypotheses.
