# Glossary

- Mission: a small activity with a role, time estimate, three steps and a result.
- Experience: a completed or adapted mission saved with a personal enjoyment rating.
- Compass: category averages computed from those self-ratings.
- Tradition: a repeatable activity scenario and invitation text.
- Circle: selected tradition ideas; not a shared social group.
- Backup: JSON containing completed entries, favourites and selected traditions. It does not move the active checklist.

Review when these domain meanings change. See [product](product.md).
