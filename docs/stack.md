# Stack

Authored HTML/CSS/ES modules, native browser dialogs/localStorage and GitHub Pages. Node >=22.13.0 runs local scripts; CI selects Node 24. No npm installation, framework, schema migration or production application server.

[Generated application facts](../context/application.md) own catalog, module, key and navigation facts. [Dependencies](dependencies.md) owns rationale; [operations](operations.md) owns commands/publication. The local Node HTTP server previews static files only and has no messaging API. Review when runtime or tooling changes.

The generated application map now includes Android package, minimum/target SDK, versions, dependency and native actions from source configuration. See [Android](android.md) for the choice/constraints and [Android router](../android/AGENTS.md) for changes. Node has no added package dependency.
