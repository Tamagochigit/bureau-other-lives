# Architecture

The production application is static HTML/CSS/ES modules on GitHub Pages. Browser source is `public/`; the explicit build whitelist is [scripts/build-pages.mjs](../scripts/build-pages.mjs). It rewrites relative .mjs imports to .js and emits HTML, styles, icons, manifest and .nojekyll. Generated output is `out/pages`; no framework, auth injection, database or private API is deployed.

`core.mjs` owns diary v1 transitions, safe backup validation/merge and truthful compass aggregation. `app.mjs` owns rendered views and event handlers. `data.mjs` owns the authored mission/tradition catalog. The unchanged diary key is `other-lives:state:v1`; prior JSON backups remain compatible. Stored record titles survive catalog retirement. Notes are escaped; there is no network data path in these modules.

`friends.mjs` renders public joint-activity ideas and a temporary selectable-text fallback. There is no address book or contact module. Previously stored `other-lives:contacts:v1` remains untouched; nothing migrates, reads, writes or deletes it. Diary backup semantics are unchanged.

`links.mjs` builds canonical public mission links and title/invitation/url payloads from known catalog ids. `sharing.mjs` prefers the native channel, then Web Share, then clipboard/selectable text. Unknown ids invoke no capability. Web Share AbortError returns silently; other share errors offer explicit copying rather than automatically transferring text elsewhere. `runtime-config.mjs` holds the frontend address. Incoming known missions display instructions without starting/writing; old invite/offer queries remain ignored.

Sharing requires a user action. No provider package, account, username or destination is imposed. Delivery belongs to the application/recipient selected by the user. Only public catalog content is shared; diary/notes are outside the sharing modules. Android receives an id only and rebuilds text from generated bundled `share-missions.json`, avoiding arbitrary bridge text/URL/recipient input. No third-party messaging SDK or network API is added.

Historical Worker/D1/auth code was removed from current main on 2026-10-05. Git history is preserved; the old external deployment/database were not deleted or migrated. Current source has no runtime link to them. [Decisions](decisions.md), [rules](../rules/README.md), [operations](operations.md) and [generated facts](../context/application.md). Review when state, sharing, hosts or build boundaries change.

Android 0.4.0 adds a Java Activity plus AndroidX WebKit, not a second product backend. The browser build is packaged through scripts/build-android-assets.mjs; android.mjs conditionally talks to an exact-origin native channel for explicit SAF export/import and public-mission sharing. All diary transitions still live in core.mjs. Browser and APK origins have separate storage; JSON merges transfer records. Runtime boundaries, build/signing and process-death limitations have one canonical home: [android.md](android.md).
